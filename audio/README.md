# Audio

The player defaults to the official YouTube embed, not this folder —
see `PLAYLIST.source` in `script.js`.

Set `PLAYLIST.source = 'file'` to play a self-hosted track instead:

    audio/money-playlist.mp3

The green ring follows its position either way. For a different
filename or format, change `PLAYLIST.src`.

If the file is missing, the button does not break: it labels itself and
links out to the track instead.

## Where the file can legally come from

- **Your own recording, mix or export** — nothing else to clear.
- **Royalty-free / Creative Commons** — Free Music Archive, ccMixter,
  Pixabay Music, Uppbeat. Check the licence allows web use and keep the
  attribution the licence asks for.
- **A licensed track** — buy a sync/web licence from the rights holder.

Commercial music cannot be downloaded from a streaming site and hosted
here; that is the rights holder's to grant. For a copyrighted track,
use the platform's own embed (Spotify, SoundCloud, Audiomack, YouTube)
instead — those carry the licence with them.
