# Gift's corrections — check before every build

Content
- Informative first. Every item specific: dates, issuer, printer/mint, material, size, weight, front, back, catalogue numbers, every design change with its date. Nothing generic, nothing vague.
- Names in words, never "2/-", "3d", "½d". Tag the issuer: (WACB), (Nigerian), (British). Naira/kobo need no tag. Biafran money lives on one Biafran Pound page.
- WACB stays abbreviated (tooltip with full name is fine).
- When text mentions another item, link to it.
- Never drop an item that exists. Every denomination of every issuer must be present. 20 kobo was never minted — not listed.
- Coins "dated 1880" were not in use then; use the year the coin itself shows (e.g. half penny = 1913 main image).
- If a year can't be proved, write "Date unknown".
- Stories (barter, cowries, manillas, redenomination, eNaira) keep their route ("How it changed"), statement and goods.
- Nothing repeated on a page (e.g. "Pre-colonial · Pre-colonial", "Naira · Naira").
- Sources live on one Sources page only (linked in the footer), not on every page.

Images
- Owner's file numbers 1, 2, 3 = oldest to newest; newest is the main image. A file named only "front" pairs with the unnamed one as back, and vice versa.
- Every coin/note image is cut out (no background) everywhere it shows: stage, home cards, versions, footer marquee. "Used as money" photos stay full.
- Trade by Barter main image = the exchange photo, cut out, arms touching both sides, not stretched.
- Front/back are never labelled on screen.

Layout
- Versions row: only versions we have images of; each on light, creased old paper; images side by side; label = year only ("Date unknown" if unproven); no hover effect; "Click to view." underneath.
- Clicking any image: full-screen, image only, an X, arrows only where there is a previous/next. Clicking outside also closes.
- No hover effects on Versions. Home cards turn to the back on hover.
- Footer marquee: endless, right-to-left, stops on hover, click opens the item; tiles on old paper.
- Hero carousel removed (it repeated the grid).
- Route line finishes as the content arrives; every stop shows its details.
- Logo A (green coin, cream ₦, dotted rim, no hole) spins on hover; it is the favicon; loader is the 3D spinning coin.
- Don't touch anything she didn't ask to change.
